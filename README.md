# hermetix-trend-breakout-strategy

WMA **추세선 돌파 전략** (롱 온리) — [hermetix-trading-core](https://github.com/tauthdev/hermetix-trading-core) 기반 모의투자 봇.

원본은 turtle-trading 프로젝트의 `BackTradingV11` (Bybit 1시간봉 백테스트, 롱/숏 양방향)입니다. 11개 버전의 실험을 거친 가장 정제된 로직을 주식 모의투자 환경에 맞게 **롱 방향만** 이식했습니다.

## 전략 아이디어

고점/저점의 **가중 이동 추세선**(최근 캔들일수록 큰 가중치)으로 다음 고점을 예측하고, 가격이 예측 범위를 크게 벗어나 위로 이탈하면(돌파) 추세 가속으로 보고 진입합니다. 상승 추세(고점 기울기 양수)에서만 진입해 역추세 돌파를 걸러냅니다.

## 동작 흐름

```
매 틱 (기본 60초, 미국 정규장 중에만)
│
├─ 추세선 계산 (완성된 캔들 lookback 개 - 기본 1시간봉 120개, 설정 가능)
│   ├─ 고점 기울기 = Σ (고점 변화량 × 가중치) / Σ 가중치
│   ├─ 예측 고점 = 마지막 고점 + 기울기, 예측 저점 = 마지막 저점 + 기울기
│   ├─ 갭 = 예측 고점 − 예측 저점
│   ├─ 돌파선 = 예측 고점 + 갭      ← 진입 기준
│   └─ 지지선 = 예측 저점 − 갭      ← 손절 기준
│
├─ 보유 없음
│   ├─ 고점 기울기 ≤ 0 (하락/횡보 추세) → 대기
│   ├─ 현재가 < 돌파선 → 대기
│   ├─ (선택) 거래량 필터: 진행 중 캔들 거래량 < 평균 × volume-ratio → 대기
│   └─ 돌파 확인 → 시장가 매수 + 브라켓 예약
│        ├─ 익절: 진입가 × (1 + profit-rate)
│        └─ 손절: 지지선
│
└─ 보유 중
    ├─ 익절/손절: 브라켓이 자동 시장가 청산
    └─ 만료: 진입 후 expire-hours(12) 경과 → 시장가 전량 매도
```

같은 1시간봉 구간에서는 한 번만 진입을 시도합니다.

## 설정 파라미터

| 키 | 기본값 | 의미 | 조정 효과 |
|---|---|---|---|
| `trend-breakout.symbols` | AAPL | 감시 종목 목록 (쉼표 구분) | 종목별 독립 진입/청산. 예산은 종목 수로 분배 |
| `trend-breakout.candle-interval` | 1h | 캔들 주기 (1m/5m/1h/1d) | KRX 브로커는 `1d` 필수 (동봉 프로파일에 반영됨) |
| `trend-breakout.lookback` | 120 | 추세선 캔들 수 (시간) | 크게 → 장기 추세 기준 (완만), 작게 → 단기 민감 |
| `trend-breakout.profit-rate` | 0.04 | 익절률 (+4%) | 손절 폭(지지선까지 거리)과의 비율을 함께 고려할 것 |
| `trend-breakout.volume-ratio` | 0 (끔) | 거래량 필터 배수 | 켜면 거래량 동반 돌파만 진입 (거짓 돌파 감소) |
| `trend-breakout.expire-hours` | 12 | 만료 청산 시간 | 짧게 → 돌파 실패 시 빠른 탈출 |
| `trend-breakout.budget-ratio` | 0.5 | 진입 예산 비율 | — |
| `trend-breakout.poll-seconds` | 60 | 판정 주기 | 짧게 → 돌파 감지 지연 감소 (스냅샷 기반이므로 의미 있음) |

## 주의사항

- **모의투자 학습용입니다.** 실제 투자 판단의 근거로 사용하지 마세요.
- **기본 브로커는 넥스트증권(미국주식)입니다.** 이 전략은 1시간봉을 사용하므로, 일봉만 지원하는 KRX 브로커(kis/kiwoom)에서 쓰려면 `spec.candleInterval` 을 `DAY_1` 로 바꾸고 lookback/만료 시간을 일 단위로 재조정해야 합니다.
- **캔들 데이터 확보 시간**: 1시간봉은 거래 시간에만 생기므로 lookback 120개 ≈ **약 18거래일 분량**입니다. 상장 직후 종목이나 데이터가 부족한 종목은 진입하지 않습니다 (에러 아님 — 조용히 대기).
- **손절 폭이 가변적입니다.** 손절선(지지선)은 추세선에서 계산되므로 진입가에서 얼마나 아래인지가 시장 상황마다 다릅니다. 변동성 큰 구간에선 갭이 커져 손절 폭도 커집니다. 손실 허용 범위가 정해져 있다면 아래 커스터마이징으로 고정 % 손절로 바꾸세요.
- **원본의 트레일링 익절선은 미구현**입니다. 원본 V11 은 가격이 익절선 위로 완전히 지나가면 익절선을 끌어올리며 따라갔지만, 여기서는 고정 익절률로 단순화했습니다 (서버가 TRAILING_STOP 주문을 지원하면 복원 예정).
- **브라켓 예약은 메모리에만 있습니다.** 재시작 시 익절/손절 예약이 사라지므로 보유 포지션을 수동 점검하세요.
- **같은 심볼을 다른 전략과 동시에 돌리지 마세요.**
- 돌파 감지가 현재가 스냅샷 기반이라, poll-seconds 사이에 돌파 후 되돌아온 경우는 놓치거나 되돌림 지점에서 진입할 수 있습니다.

## 커스터마이징 포인트

- **고정 % 손절**: `TrendBreakoutStrategy.decideEntry()` 의 `stopLoss = trend.supportLine...` 을 `price × 0.98` 로 교체
- **돌파선 민감도**: `TrendLine.breakoutLine` 은 `예측고점 + 갭×1`. 갭 배수를 줄이면 (예: `gap × 0.5`) 더 일찍 진입하고, 늘리면 더 확실한 돌파만 잡습니다
- **지표 교체**: `TrendLine.of()` 가 유일한 지표 계산부입니다. 단순 이동평균, EMA 등으로 교체해도 전략 골격은 그대로 동작합니다
- **거래량 필터 활성화**: `volume-ratio: 0.5` 부터 시작해보세요 (진행 중 캔들 거래량이 가중 평균의 절반 이상). 1시간이 다 차지 않은 캔들과 비교하므로 보수적으로 잡아야 합니다
- **다중 종목**: `trend-breakout.symbols: AAPL,NVDA` 처럼 나열하면 종목별 독립 상태로 동시 운용됩니다 (예산은 자동 분배)

## 실행

```bash
# 넥스트증권 (미국주식, 기본)
export NEXT_CLIENT_ID=... NEXT_CLIENT_SECRET=...
./gradlew bootRun

# 한국투자증권 모의투자 (KRX, 일봉 60개 추세선 프로파일 동봉)
export KIS_APPKEY=... KIS_APPSECRET=... KIS_CANO=...
SPRING_PROFILES_ACTIVE=kis ./gradlew bootRun

# 키움 모의투자 (KRX)
export KIWOOM_APPKEY=... KIWOOM_SECRETKEY=...
SPRING_PROFILES_ACTIVE=kiwoom ./gradlew bootRun
```
